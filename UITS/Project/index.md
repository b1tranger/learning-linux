# UITS Project: Tavern of Life

[🏠 Root](../../README.md) / [📁 UITS](../index.md) / **Project**

---

### 📖 About
**Tavern of Life** is a terminal-based interactive story, text-adventure, and RPG engine built using Bash, featuring rich terminal ANSI styling, sound, Whiptail / Zenity GUI integration, and interactive mechanics.
